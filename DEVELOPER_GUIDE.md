# Developer Guide: Game Level Progression System

## Overview

This document explains the **game level progression system** for developers who need to understand, modify, or extend the wave-based enemy spawning mechanics.

**Key Concept:** The game progresses through discrete "game levels" (1-20+), each with predefined "waves" of enemies. This is separate from the "player level" XP system used for upgrade progression.

---

## Quick Summary

### The Two "Levels"

| Concept | What It Does | Where Tracked | Affects |
|---------|-------------|----------------|---------|
| **Game Level** | Enemy difficulty progression | `self.game_level` | Wave configuration, enemy types |
| **Player Level** | Unlock upgrade choices | `self.level` | Upgrade menu, XP requirements |

### How a Level Works

```
Level Start (game_level = 5)
    ↓
[Spawn Wave 0] → Wait 2 seconds → [Spawn Wave 1] → Player defeats all enemies
    ↓
All enemies gone → 3-second rest period
    ↓
game_level = 6 → Repeat
```

## System Architecture

### Configuration: `constants.py`

```python
LEVEL_REST_DURATION = 3000  # 3 seconds between levels

GAME_LEVEL_WAVES = {
    # Format: level_number: [wave_list]
    # Each wave: (enemy_type, count, spawn_delay_ms)
    
    1: [('basic', 5, 0)],                           # 1 wave, 5 basic enemies
    5: [('basic', 10, 0), ('triangle', 3, 2000)],  # 2 waves, 2s apart
    20: [('pentagon', 8, 0), ('triangle', 15, 1500), ...],  # 6 waves
}
```

**Wave Tuple Format:**
- **enemy_type** (str): `'basic'` | `'triangle'` | `'pentagon'`
- **count** (int): Number of enemies to spawn
- **spawn_delay_ms** (int): Milliseconds from level start to spawn this wave

### Game State: `top_down_game.py`

**Critical Variables:**
```python
self.game_level: int           # Current level (1, 2, 3, ...)
self.current_wave: int         # Which wave in current level (0-indexed)
self.wave_timer: int           # Milliseconds until next wave spawns
self.is_resting: bool          # True if in rest period between levels
self.level_rest_timer: int     # Milliseconds remaining in rest
self.game_level_text: str      # Canvas text item ID for display
```

### Update Loop Integration

Every 20ms (50 FPS), the game calls:
```python
def update_logic(self):
    # ... other updates ...
    self.update_game_level_progression()  # ← Wave management happens here
```

## Wave Spawning Flow

### Step 1: Start of Game
```python
# In __init__():
self.game_level = 1
self.start_game_level()
```

### Step 2: Spawn Wave 0
```
start_game_level()
    ├─ Clear all enemies: self.enemies.clear()
    ├─ Reset wave: self.current_wave = 0
    └─ Call: _spawn_next_wave()
        ├─ Look up GAME_LEVEL_WAVES[1]
        ├─ Get wave 0: ('basic', 5, 0)
        ├─ Spawn 5 basic enemies at random positions
        ├─ Increment: self.current_wave = 1
        └─ Calculate delay: wave_timer = (next_wave_delay - current_delay)
```

### Step 3: Wait for Wave Completion
```
update_game_level_progression() called every 20ms:
    if wave_timer > 0:
        wave_timer -= 20ms
    elif all enemies defeated:
        spawn_next_wave()
```

### Step 4: End of Level
```
When current_wave >= total_waves:
    ├─ Set: is_resting = True
    ├─ Set: level_rest_timer = 3000ms
    └─ No more waves spawn

During rest period:
    update_game_level_progression() decrements level_rest_timer
    
When level_rest_timer <= 0:
    ├─ game_level += 1
    └─ start_game_level()  ← Repeat for next level
```

## How the System Handles Different Cases

### Case 1: Waves Complete Before All Enemies Die

**Scenario:** Level 5 has 2 waves. Wave 1 spawns 10 basic enemies. Player only kills 8.

**What happens:**
```
Wave 0: 10 basic enemies spawn at 0ms
Wave 1: 3 triangle enemies spawn at 2000ms (joins the 2 remaining basic enemies)
→ 5 enemies total on screen
→ Player defeats all 5
→ is_resting = True
→ Next level starts
```

### Case 2: Levels Beyond 20

**Scenario:** Player reaches level 21, which is not in `GAME_LEVEL_WAVES`.

**What happens:**
```
_spawn_next_wave() checks if level in GAME_LEVEL_WAVES
    → Not found
    → Calls: _spawn_next_wave_autogenerated()
        ├─ Calculates: ~6 waves for level 21
        ├─ Calculates: ~30 total enemies
        ├─ Splits: 60% triangles, 30% pentagons
        └─ Spawns waves with 3-second intervals
```

### Case 3: Player Pauses During Wave

**Scenario:** Level 3 is in progress, wave 1 hasn't spawned yet. Player pauses.

**What happens:**
```
Game pauses → update_logic() skips entirely
→ wave_timer is not decremented
→ When game resumes, timer picks up where it left off
→ Wave spawns on schedule
```

## Method Reference

### Core Methods

#### `start_game_level() -> None`
- **Purpose:** Initialize a new game level
- **Called by:** Game initialization, end of rest period
- **Does:**
  - Clears all enemies
  - Resets wave counter to 0
  - Calls `_spawn_next_wave()` to spawn first wave

#### `_spawn_next_wave() -> None`
- **Purpose:** Spawn the next wave or trigger rest period
- **Called by:** `start_game_level()`, `update_game_level_progression()`
- **Does:**
  - Looks up current level in `GAME_LEVEL_WAVES`
  - Spawns all enemies for current wave
  - Increments `current_wave`
  - Sets timer to delay until next wave
  - If last wave: sets `is_resting = True`

#### `_spawn_next_wave_autogenerated() -> None`
- **Purpose:** Generate a wave for levels beyond 20
- **Called by:** `_spawn_next_wave()` when level not in dict
- **Does:**
  - Calculates number of waves based on level
  - Calculates enemy composition (basic/triangle/pentagon ratio)
  - Spawns proportional mix
  - Sets 3-second delay between waves

#### `_get_spawn_position() -> Tuple[int, int]`
- **Purpose:** Get random spawn location outside screen
- **Returns:** (x, y) tuple
- **Does:**
  - Randomly chooses edge (top, bottom, left, right)
  - Returns position 200px outside that edge

#### `_spawn_enemy_by_type(x: int, y: int, enemy_type: str) -> None`
- **Purpose:** Create a specific enemy type
- **Parameters:**
  - `x, y`: Spawn position
  - `enemy_type`: `'basic'` | `'triangle'` | `'pentagon'`
- **Does:**
  - Creates appropriate enemy class
  - Appends to `self.enemies[]`

#### `update_game_level_progression() -> None`
- **Purpose:** Update wave timers and level progression
- **Called by:** `update_logic()` every 20ms
- **Does:**
  - If resting: decrements rest timer, advances level when done
  - If not resting: decrements wave timer, spawns next wave when ready
  - Updates canvas display with current level

## Debugging

### Check Current Wave Status

Add to `update_logic()` temporarily:
```python
if some_debug_condition:
    print(f"Level {self.game_level}, Wave {self.current_wave}, "
          f"Timer: {self.wave_timer}ms, "
          f"Enemies: {len(self.enemies)}, "
          f"Resting: {self.is_resting}")
```

## Performance Considerations

### Wave Spawning Optimization

- **Current:** Spawns all enemies in a wave instantly
- **Impact:** No performance issues up to 100+ enemies per wave

### Wave Timer Precision

- **Resolution:** 20ms (logic update rate)
- **Accuracy:** ±20ms (good enough for gameplay)
- **Could improve:** Use higher-precision timer if needed

### Memory Usage

- **Per wave:** Negligible (just tuple storage)
- **Per level:** ~100 bytes for wave data
- **Total:** ~2KB for all 20 levels + auto-gen

### Ideas for Enhancement

### Extending Auto-Generation

Current formula for levels 21+:
```python
num_waves = min(3 + (level // 10), 8)
total_enemies = 5 + (level // 2)
pentagon_ratio = min(0.4, 0.02 * level)
```

Could improve by:
- Adding health scaling per level
- Varying enemy speeds
- Mixed difficulty within single level
- Boss mini-waves
